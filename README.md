# Chicago Family Cars

## Overview
Chicago Family Cars is an Android mobile application built with Java in Android Studio. The app provides an image-based interface for browsing family-oriented vehicles and accessing official vehicle websites and local Chicago dealerships.

## Features

- **Home Page**
    - The home page displays a grid containing images of available vehicles.  
    - Each car image supports two types of interaction:  
        - Tap: Opens the selected car's full-screen image.  
        - Press and hold: Displays a menu with three available actions:  
            - View Full Image  
            - Open Website
            - Show Dealers  

- **View Full Image**
    - Selecting View Full Image opens a new screen containing a full-screen version of the selected vehicle image. The image can also be tapped from this screen. Tapping the image opens the vehicle's official website.

- **Open Website**
    - The Open Website option externally opens the official website associated with the selected vehicle. This functionality is the same as tapping the vehicle image on the Full Image screen.

 - **Show Dealers**
    - Selecting Show Dealers opens a new screen containing a list of dealerships where the selected vehicle can be purchased.
